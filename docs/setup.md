# KNOW THE MICE — Installation & Setup Guide

## Windows Host Setup

1. **Option A: MSI Installer (Recommended)**
   - Double-click `KnowTheMice-Setup-v1.0.0-win-x64.msi`.
   - The installer automatically registers Start Menu and Desktop shortcuts, adds the Windows Firewall rule, and registers an uninstaller.

2. **Option B: Standalone Portable Executable**
   - Run `KnowTheMice.Host.exe`.
   - The application runs without administrator elevation or registry modifications.

3. **Firewall Confirmation:**
   - If prompted by Windows Defender Firewall, select **Private networks (home or work)** and click **Allow access**.

---

## Android Mobile Client Setup

1. Install `KnowTheMice-v1.0.0-release.apk` on your Android device (Android 10+ required).
2. Connect your phone to the same Wi-Fi router as your computer.
3. Open the app. Your PC appears in the discovery radar within 3 seconds.
4. Tap **Pair** and type the 6-digit code shown on your computer monitor.
